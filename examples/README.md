# Examples — worked artifacts

These are **snapshots of one real capstone** (LEASH) kept as *format references*, not templates to copy. Use them to calibrate depth and structure when producing your own LOI, requirements doc, or red-team log. Your own artifacts go in your working repo, not here.

## `loi/`

| File | What it shows |
|------|---------------|
| `LEASH-LOI-Submission.md` | The submitted LOI — final form of a Part 1 + Part 2 submission |
| `LEASH-LOI-full.md` | The fuller working draft behind the submission |
| `red-team-log.md` | How to log an AI red-team pass: findings, evaluations, override decisions |
| `phase2-use-cases.md` | Use-case enumeration feeding the requirements doc |

## `requirements/`

| File | What it shows |
|------|---------------|
| `LEASH-atomic-requirements.md` | Problem statements → numbered atomic `"The protocol shall …"` requirements — the format `knowledge/process/architecture-diagramming.md` prescribes |
