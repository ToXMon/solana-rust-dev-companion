# Solana GTM and getting noticed

Load this resource first:

- `resources/knowledge/gtm/getting-noticed.md`

## Rules

- Proof beats claims.
- Show the demo before the announcement.
- Translate technical features into user or reviewer value.
- Use AI as editor and operator, not as a ghostwriter.
- Reject generic hype, fake traction, engagement bait, and unsupported claims.

## Procedure

1. Identify the audience: hiring team, hackathon judge, grant reviewer, user, ecosystem peer, or founder/operator.
2. Extract proof: repo, tests, deployed program, screenshots, transaction links, demo, README, and known limitations.
3. Write the one-sentence positioning.
4. Create a 60-second demo script.
5. Create a launch checklist and post bank.
6. Create one clear ask.
7. Add follow-up actions that help others publicly.

## Output

Return:

1. Positioning sentence.
2. Profile/bio options if relevant.
3. README/demo improvements.
4. 60-second demo script.
5. Launch post variants.
6. Supporter/reply plan.
7. No-slop risk check.
